# MIDI Research Log

`docs/midi-captures/`.

## Experiment template

```text
## YYYY-MM-DD - Control name

Setup:

Capture:
- docs/midi-captures/YYYY-MM-DD-description.txt

Observations:
- raw-message patterns and changes

Hypothesis:
- suspected mapping, if any

Verification:
- transmitted test values and device response

Conclusion:
- result and confidence
```
